# #33：对局大脑知识工具模式交付

任务：[issue #33](https://github.com/dwroy/agent-sts2/issues/33)，包括[主管补充的 #32 范围及 #31 不做试验决定](https://github.com/dwroy/agent-sts2/issues/33#issuecomment-6325199832)。分支 `issue-33-brain-agent-mode`，分配基线 `8bdb952c92130b75c83824ac9000c70255fb3aa7`。本开发会话的原生 turn_context 已核为 `gpt-6.1-sol/high`；不代表生产大脑已切换。

## 交付行为

生产入口不再渲染全量知识前缀或附加开卷/策略段。题内状态、选项、投影、工作记忆及原有格式校验保留；经验段、开卷机械资料、经验/策略和外部汇总通过14个只读知识工具取得，返回来源、版本与 SHA。工具不提供原日志 SQL、任意路径、shell、文件写入或网络搜索；经验工具不读复盘原文，保留知识条目本身的证据与反证。

Codex 使用 app-server，默认 GPT-6.1 Sol/high。DeepSeek 默认 max，经已有 dsh/Nova 启动器，旧直连 API 仅在历史适配器中保留。复用 `BRAIN_RUN_CONFIG` 的按局引擎/强度开关，不运行 #31 的交替试验，不设置跨引擎自动兜底。调用数/时间、实际选择和来源继续进入 run-config/brain 日志。

主循环的构筑出题与可用额度门禁已解除对旧 DeepSeek API client 的依赖；dsh 无旧 key 也能得到休息、选牌和事件题，原直连额度不冒充 dsh 额度。生产知识引擎不再沿旧升级链调用 Claude。固定内存对局分别验证 Codex/DeepSeek 三类真实屏幕出题与单次派发，不启动游戏或模型。

预算初值为每题8次查询，Codex总300秒/预留作答120秒，DeepSeek总900秒/预留300秒。超过查询阶段时间或调用数后，关闭查询 harness，用同一引擎及精确记录的工具结果无工具作答；重问不给新工具额度。错误查询返回错误文本，异常失败题也保留已发生调用。服务彻底不可用或硬取消不能伪造作答，原 Codex 恢复等待不冒充完成。

Codex 的原生 MCP 配置会自动暴露三个通用资源工具；实际离线请求检查发现后，改用 app-server 客户端 `gkb` 命名空间桥，把允许的工具调用转发到同一个进程内 MCP。最终实际序列化清单为14个知识函数，作答阶段清单为空；未开放 shell、文件、网络、项目文档或 hooks。dsh 也先禁用所有继承插件，再只插入必要内核、Nova 引用、知识 MCP 与流式进展观察器；其自动资源工具同样移除。

此为 Roy 授权的全局大脑架构调整，铁甲战士的请求知识组织与默认强度也随之改变，不能声称逐字节等价。除精确导入 #26 的公共统计投影外，没有修改既有角色知识、游戏机制、模拟参数、出牌/药水/SL/价值规则或原有证据分母；角色私有知识按原角色加载，外部数据不计本角色实盘验证。
