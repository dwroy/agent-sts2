# 静默牌组规模与加牌边际收益学习

请求：`roy-20261010-silent-deck-size-value`。Roy 的原话是：“问一个问题，是否牌越多越好，如何衡量，这个可以让学习者来回答，并看能否获得收益和指导”。这是一项学习目标，以下只规定证据与交付要求，不提供任何游戏结论、牌表或阈值。

本任务通过现有手动 `strategy-proposal` 通道执行。先核对根目录 `notes/strategy-research-silent.json`、本批实际登记、冻结输入与本文 SHA；只有任务、角色、派发局号和请求相符才承接。派发的十个局号是入口锚点；研究来源为冻结清单的全部已结束静默局，不能把十局冒称为全历史。该专题独立于已完成的核心组合学习，不重派原任务、不改写其报告。

## 要回答的问题

1. **size_outcome：牌是否越多越好。** 根据实盘给出有证据的回答，包括无法得出的结论。按各幕或战斗前真实牌组规模、组成及资源取样，不能用最终牌组倒填早期，也不能只看活到 boss 的样本。按已观察进阶、实际版本和成功大脑来源分层；主战绩保持纯 Codex，其他来源单列。整局、逐阶段到达与战斗消耗分开，首试与含 SL 最终结果分开，同局重复尝试不当独立样本。
2. **marginal_value：怎样衡量新增一张牌的收益与代价。** 从数据提炼可解释、可复算且大脑能使用的指标。核查实际加牌、跳过、删牌和其他牌组变动的来源与时点；观察关键组件实际抽到/建立时点、手牌与费用是否可用、每轮实际输出/生存及 HP/药水/金币等资源变化。哪些因素可比较、哪些无法隔离，由学习者从证据决定。没有受控对照的结果只能写观察或假设，不能把共现、模型预测或大脑理由直接当因果证明；不预设固定“最佳张数”、统一阈值或“越薄越好”。
3. **construction_guidance：指导后续选择。** 形成少量有适用条件的拿牌/跳牌/删牌评估原则，说明当前缺口、组合是否真实启动、资源约束、已见替代或过渡以及失效条件。与已入库的四个核心候选及已有同主题条目核对、合并去重；不能只输出统计表或增加重复的单局经验。具体牌、组合、公式、阈值和指导必须由学习者从本角色证据得出。
4. **counterexamples：支持与反例。** 每条建议带局号、层、回合/决策和原始证据字节位置/SHA；同时列支持、反例、覆盖人数/独立局分母及未覆盖范围。赢局和早死局均需纳入。较大或较小牌组的失败不能单因归责，低阶胜利不直接外推 A10。
5. **limitations：收益及验证限制。** 区分历史相关性、固定局面验证、消费者读取与后续真实采用。没有可比改前/改后样本时，预期收益写待验证，不能声称胜率已改善。列后续需要观察的指标和证据不足条件，不为取得对照而运行 play、修改对局参数或在线调用大脑。
