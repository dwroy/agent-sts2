# 2026-09-28 新旧两版决策逻辑对比：1910898（旧） vs fcbe2a8（新，phase2 HEAD）

## 0. 对比对象与结论先行

| | 旧版 OLD | 新版 NEW |
|---|---|---|
| 代码 | `1910898`（消融实验前最后一版 A8 代码；13 局 A8 实际跑在 c8a74b5…1910898 这一串逐步演进的提交上） | `fcbe2a8`（phase2 HEAD，距旧版 113 个提交，src/ 净增约 6800 行） |
| 运行配置 | `ESCALATION_CHAIN=deepseek`：Jev 低置信时由 DeepSeek 代选；`RUN_PLAN=v1`、`FIGHT_PLAN=v1`，DeepSeek 给出具体药水时机、铺垫牌、关键回合，全部是软权重 | `ESCALATION_CHAIN=none`（Jev 最终决定）；DeepSeek 只给封闭词表里的战略意图（`src/strategy/intent.ts`），先过校验器（`plan-validator.ts`），再由代码翻译成过滤和权重 |
| A8 结果 | 13 局，平均第 30.6 层；过一幕 boss 12/13；过二幕 3/13；到最终 boss 2/13 | 44 局（5JU3 起，不含 07:07 刚结束的 Q97B/F23），平均第 26.2 层；过一幕 30/44；过二幕 6/44；到最终 boss 0/44 |

统计折扣：
- 过一幕 12/13 对 30/44，Fisher p≈0.15；到最终 boss 2/13 对 0/44，p≈0.05。样本小，下面的"嫌疑"都是按证据强弱排序，不是定论。
- 消融实验（旧代码 5a513d2，每组 5 局）里，**只有代码 + Jev、完全没有 DeepSeek 的 jev 组最好**：平均 33.6 层，过一幕 5/5。所以"去掉 DeepSeek 兜底、Jev 最终决定"这一条本身，不太可能是主因。

**一句话结论**：新版并没有少打精英。差距主要来自三处：
- 新版把药水"硬留给 boss"，精英战里少喝药、多掉血、多死；
- 新版把休息点几乎全改成回血，锻造变少，boss 前输出不够；
- 新版一幕 boss 输局从 1/13 升到 10/40。进场血量和药水数差不多，输的是输出。

### 1.2 代码否决 Jev（战斗）

两版完全相同（旧 combat-plan.ts:1244-1301，新 :2031-2092）：
- 走廊战：Jev 置信 <0.3 且选的不是第一名 → 换成代码第一名。
- 精英/boss：Jev 选喝药线且置信 <0.5 → 如果不喝药的线掉血不更多，换成不喝药线。
- 攻击药水线置信 <0.5 → 换成第一名。
- 走廊战喝药线不是第一名 → 需要置信 ≥0.75 才保留。
- 精英/boss/危险回合置信 <0.4 → 换成能全面压制它的线。

新版在这之上加了三点：
- 同回合记住被否决的药水；
- 沙坑里保留狂乱逃离线（`keepsEscapes`）；
- 记录偏离意图的选择（`intent_deviation`）。

### 2.2 开战计划（FIGHT_PLAN）

旧版（旧 fight-plan.ts）：
- 内容：approach（race/setup/defend）、setup 最多 3 张铺垫牌、focus 先打谁、每瓶药水的用途、关键回合和总结。
- 铺垫牌：前 3 回合里，多打计划铺垫牌、且在护栏松弛内的线，会从代码直接出变成问 Jev（旧 combat-plan.ts:1058-1066）。
- 药水用途进求解器成本（`planPotionCost`，旧 fight-plan.ts:233-248）：
  - early：T≤2 免费；
  - big_hit：大招回合免费，否则 +6；
  - emergency：+10；
  - save：+20。
- **代码自动喝药**（旧 combat-plan.ts:947-969，`combat/plan-potion`）：
  - early 在 T≤2 喝；
  - big_hit 在来袭减格挡 ≥max(12, 25% 当前血) 的回合喝（旧 :787）。
- 旧版**没有整局级的药水保留**：1910898 的 run plan 里没有 savePotions，03ef4bd 的 savePotions 是消融时才上的。

新版：
- 内容：objective（kill_fast/preserve_hp/scale_then_kill/race）+ reasons + kill_priority；threat 和 summary 只作为给 Jev 的上下文。
- 删掉了药水时机、自动喝药、setup 牌单和 big_hit。
- 校验器处理：
  - 残血时 scale_then_kill 改为保血；
  - 敌人会拖死我方时，preserve_hp 按 kill_fast 打（`grindOutlasts`）；
  - 随从排在最后；
  - 判断类分歧保留原意图并记日志。

## 4. 火堆（回血 vs 锻造）

基础分两版相同（旧 rest.ts:38-41，新 :45-48）：
- HEAL：血 <50%，或"boss 前"且 <85%，或距 boss ≤4 层且 <65% → 10；<65% → 5；其余 1。
- SMITH：6。
- 牌组伤害缺口 ≥8 且血 ≥65%、不在 boss 前时，SMITH 再 +2。
- 代码直接决定的差距门槛为 3。

| 差异 | 旧版 | 新版 |
|---|---|---|
| "boss 前"的定义 | 距 boss ≤2 层，或下一节点强制是精英/boss | 另加：2 个节点内所有路线都遇精英、中间没有火堆或商店（77QX） |
| 计划加减分 | rest=heal：HEAL +3；rest=smith：血 ≥50% 且不在 boss 前时 SMITH +3 | **距 boss ≤6 层且血 < entry_hp（0.85/0.9）时 HEAL +8**，并直接返回（intent.ts:484-497）；entry 被上调时 HEAL +3；preserve 且低于目标时 HEAL +4、SMITH −2；push 且血 ≥55% 时 SMITH +3、HEAL −2 |
| Pantograph | 不计 | 下一层是 boss 时把 +25 血计入 |

**效果**：距 boss 3–6 层、血 80% 时，旧版 SMITH 6 对 HEAL 1，代码直接锻造；新版 HEAL 1+8=9 对 SMITH 6，差距刚好 3，**代码直接回血，不问 Jev**。

## 5. 卡牌奖励 / 商店 / 删牌 / 事件

### 5.1 卡牌奖励

基础估值两版相同（card-value.ts）：
- 跳过线 50；
- 一幕前置伤害 +12、无 AOE +14、抽牌 +5、成长 +10、第 5 层起格挡少 +5；
- 牌组超过 22 张且估值 <70 时，每多一张 −1.5（最多 −15）；
- want +20、avoid −15、缺格挡牌 +6、boss 专属加分（例如女王格挡 +8、成长 +6）。

新增：
- **必备角色加分**（`mustHaveBonus`，run-plan.ts:522-539）：卡的角色在 needs 里、且牌组里该角色少于 2 张时 **+14**，否则 +4。格挡角色在血 <50%、比 block_target 少 2 张以上时 **+21**。boss 缺口 ≥8 且格挡目标已满足时，格挡加分减半。needs 几乎总含 aoe/block/frontload/strength，所以大多数候选牌都拿得到这个加分。
- **boss 伤害缺口加分**（boss-clock.ts:377）：旧版为 min(12, 0.4×缺口 + 成长牌 2)；新版在缺口 ≥8 时为 min(16, 缺口/2 + 2)。缺口本身也更大：按 A8 血量算，还乘了 boss 的"实际兑现比例"（帝王蟹 0.55、女王 0.75、异鱼 0.65）。
- avoid 的卡或角色**直接不出现在选项里**。如果全部被 avoid，代码直接跳过。

实际结果：
- 跳过率：旧版 68/186（37%），新版 120/513（23%）。
- 一幕结束时牌组大小几乎一样：20.7 对 20.9 张。

### 5.2 商店

不变的部分：
- 卡牌分 = 估值 − 62 − 价格/25；
- 删牌：基础牌 ≥4 张或有诅咒时 30，否则 8；
- 血 <45% 且有空药水格时，药水分 = 34 − 价格/25。

新增：
- 有空格时的药水分 = (二幕起且空 ≥2 格 ? 14 : 8) − 价格/25，**一幕也生效**（旧版只在二幕起）。

## 6. 战斗

### 6.1 求解器权重

基础权重两版相同（旧 turn-solver.ts:1114-1125，新 :1385-1400）：
- hp = 1 + 1.5×max(0, 0.6−血%)/0.6；
- damage：boss 0.8、精英 0.7、走廊 0.45；
- 易伤 2.5+、力量 5、击杀 6+1.2×威胁；
- 长期价值 × 战斗长度系数。

新增的意图系数（intent.ts:277-300）：

| 意图 | hp | damage | 长期价值 |
|---|---|---|---|
| preserve_hp | ×1.4 | ×0.85 | ×0.8 |
| scale_then_kill | ×1 | ×0.9 | ×1.5 |
| kill_fast | ×0.9 | ×1.2 | ×0.7 |
| race | ×0.85 | ×1.3 | ×0.5 |
| hp_policy preserve | ×1.25 | ×1 | — |
| hp_policy push | ×0.9 | ×1.1 | — |

- 两个 preserve 叠加后 hp ×1.75、damage ×0.85。血 <30% 时 hp 系数至少为 1。
- 自动降级：
  - act boss 落后时钟时，preserve 按 balanced 打（`combatPolicy`）；
  - scale_then_kill 在剩余不到 3 回合或没有铺垫牌时改为 kill_fast；
  - preserve_hp 会被拖死时改为 kill_fast。
- 随机目标：旧版按"先打血最少的"计期望（会假设随机伤害打出击杀）；新版按"打在血加格挡最高的敌人上"（`randomVictim`）。更保守，但不再误判斩杀（S6AG）。

## 8. 差异里最可能导致新版变差的地方（按证据强弱排序）

数据口径：`logs/decisions.jsonl` 中每场战斗第一个和最后一个决策的血量与药水；精英由 fight-plans.jsonl 的 kind=elite 判定；阵亡那场的掉血按进场血量计。

| 战斗类型 | 旧 13 局 | 新 44 局 |
|---|---|---|
| **一幕精英**：场次 / 进场血% / 掉血（%最大血） / 用药数 / 阵亡 | 8 / 75 / **25.9** / **1.1** / 0 | 28 / 80 / **41.9** / **0.6** / **3** |
| **二幕精英** | 17 / 76 / 39.5 / 0.9 / 2 | 34 / **69** / 44.9 / 0.9 / **8** |
| 一幕 boss：进场血% / 药水 / 阵亡 | 93.6 / 1.8 / **1/13** | 86.7 / 1.9 / **10/40** |
| 二幕 boss：进场血% / 药水 / 阵亡 | 78 / 1.7 / 4/7 | 76 / 1.5 / 12/18 |
| 走廊：一幕 / 二幕 / 三幕 掉血% | 13.2 / 23.4 / 27.7 | 14.7 / 23.0 / 39.2 |
| **阵亡时药水栏还有药** | **1/13**（非 boss 死亡 1/6） | **15/44**（非 boss 死亡 **11/22**） |

### 第 1 名：药水"硬保留给 boss"——精英战少喝药，多掉血，死时药还在

- **机制**：非 boss 战直接删掉喝 reserve 药水的线，连能赢的线也删。放行条件是血 <25%、所有线都死、或只剩下一击+3。DeepSeek 几乎每版计划都 reserve 2–3 类，二幕最常见 block+damage+strength，也就是腰带上大部分药水在整幕都被锁住。旧版只有开战计划里的软成本（save +20）；early/big_hit 还会让代码主动喝。
- **数据**：
  - 一幕精英用药从 1.1 降到 0.6 瓶/场，掉血从 26% 升到 42% 最大血，阵亡 0/8 → 3/28；
  - 二幕精英阵亡 2/17 → 8/34；
  - 阵亡时还有药：1/13 → 15/44；非 boss 死亡里 11/22 带着药死。
- **复盘证据**（notes/lessons.md）：
  - 77QX（F22 猎人杀手，速度药水 reserve block，揣到死）；
  - XMY2（F24，两瓶药要到 T5 所有线都死才进选项）；
  - N95W（F25 感染棱柱，两瓶到 T4、12 血时才按 <25% 放行）；
  - G8F1（两瓶保留药在 F31、14% 血时才放行用掉，进 boss 0 药）；
  - EN55（F8 骇鳗，鲜血药水 T9、7 血才喝）；
  - PKB0（再生药水 T8、2 血才喝）；
  - 5JU3（保留的超巨化药水到 T6 所有线都死）。
- **折扣**：其中一部分是"未建模药水不进任何线"（EGX7、KGR6、K8TC、11LC），与 reserve 叠加，是同一个"药不喝"的结果。
- **可以验证的改法**：reserve 改回软成本，或者精英战完全放行；放行线从"下一击+3"提到"预计掉血 ≥ 进场血的 30%"。用 decision-replay 对上面几局回放。

### 第 2 名：火堆几乎全回血，锻造少，boss 输出不足

- **机制**：entry_hp 取 0.85/0.9（来自档案）。距 boss ≤6 层、血低于目标时 HEAL +8，加上 preserve 的 HEAL +4/SMITH −2，"boss 前"又扩到 2 格内的强制精英。结果是 80% 血时代码直接回血，不问 Jev。
- **数据**：二幕锻造率 24% → 5%（3/66）；一幕 30% → 20%；新版锻造时的平均血量高达 87–93%；二幕末已升级牌 5.6 → 3.4。
- **复盘**：新版 boss 输局的主因几乎都是"输出低于时钟"：
  - 一幕：VUV4 28.3/32.2、T86W 15.3/19.4、X8R8 28.2/32.2、HCBJ、11LC、FEY6（boss 只剩 3 血）、1DR1；
  - 二幕：M9PL 23.6/53.5、9LSQ 23/49、PCGH、5507、EHJZ、YG3H、77UJ；
  - 三幕：RTF3。
  这几批复盘的记录也写了"deck output below clock（5/5）"。
- **折扣**：消融组（旧代码）二幕锻造也只有 13%，所以二幕这部分不全是新代码造成的；但一幕锻造率 46% → 20% 的下降是新版特有的。

### 第 3 名：一幕 boss 输出不足（牌组质量和战斗权重），进场条件相同却多输

- **现象**：一幕 boss 进场血 94% 对 87%、药水 1.8 对 1.9，差别不大，但阵亡 1/13 → 10/40。
- **可能的机制**（叠加）：
  - ① 第 2 名的锻造减少；
  - ② needs 几乎固定为 aoe/block/frontload/strength，每张沾边的牌 +14，格挡在低血时 +21，稀释了原有的输出估值。跳过率 37% → 23%，一幕牌组张数不变，所以是牌的质量变了，不是数量；
  - ③ 旧版每局约 5 次由 DeepSeek 改选的非战斗决定（开局稀有牌、在 Jev 选跳过时拿牌、拿力量牌）没有了；
  - ④ 一幕 preserve 占计划的一半：走廊护栏在血 <75% 就开（旧版一幕不开）、hp ×1.25，让一幕走廊少打伤害。
- **折扣**：消融 jev 组（无 DeepSeek、旧代码）一幕 5/5，说明第 ③ 条不是必要条件，更可能是新意图层（needs、preserve、reserve）本身的副作用。

### 第 4 名：地图——精英数量没变，但进精英时血更低、强制精英更多

- **机制**：
  - avoid_elites（二幕占计划的 76%）直接过滤下一节点的可选精英；
  - 牌组伤害门槛（一幕 20、二幕 30/回合）和 74%/90% 的血量门槛拦下可选精英；
  - 存活率每少 1 扣 40 分。
  结果是高血时避开可选精英，之后在低血时撞上绕不开的精英。飞行靴被用来躲强制精英（1DR1，一幕 0 精英）。
- **数据**：一幕精英数 0.62 对 0.60，**没有少**；二幕精英进场血 76% → 69%，阵亡 2/17 → 8/34。强制精英死亡：VQ7J（F11，只剩一条线）、KQK2、VF5C、Z7D7（选了"宝箱→商店→精英"而不是"宝箱→休息→精英"）、N7KR、KGR6、N95W、K7G9。
- **折扣**：新版把路线成本换成实测 p75 以后，强制精英在路线评分里定价更高，这本身是修复。问题更多在 reserve（第 1 名）让同样的精英更伤。

### 第 5 名：Jev 最终决定、没有兜底，加上"costs"标签把 Jev 往保守线上引

- **机制**：非战斗低置信不再升级。战斗里 boss 低置信只剩"被压制的线"替换。preserve 下给 Jev 的标签把伤害线写成"costs X HP"，Jev 普遍跟标签走（intent.ts:652 的注释：5JU3、KQK2、9V09 三局里 0/76 个"breaks"选项被选）。
- **数据**：decision-log 记录，截至 09-28 06:51 累计 10 次 boss 低置信选择中，代码第一名更好 0/10。也就是说 Jev 在 boss 里的近似猜测并不比代码差。
- **结论**：这一条目前证据最弱，保留在名单里主要因为事件和开局选择的质量无法量化。建议做一次对照：同一版代码只把 `ESCALATION_CHAIN=deepseek` 打开 5–10 局。

**被数据否定的假设**："新版因 avoid/门槛少打一幕精英 → 牌组弱"。一幕精英 0.62 对 0.60 场/局，基本相等。

## 9. 新版确定更好的地方（无论如何都该保留）

- **事件**：
  - 过期的结束画面会等它消失，不再盲点第 0 项（X226 死于此）；

- **商店**：显示卡牌费用和类型；最好的药水保留在视野里；满腰带可以换药；离开要付存款的机会成本（RTF3 带着 1292 金死）。

- **Boss 时钟**：A8 血量、帝王蟹和同族按部位计算、能力牌按实际打出回合计、狱火等每回合伤害。
