# sts2.fun Silent A10 离线统计（#24）

日期：2026-10-21。来源：`external:sts2fun`。本报告由开发会话完成数据接入与描述统计；没有提炼或上线游戏知识，没有改题面、Jev、决策者或 live。外部样本不能计入本系统实盘分母。

## 结论

同版本主样本为 v0.111.0 的 1,739 局、98 个整数玩家账号、492 胜（28.3%）。拿牌频率足以形成有分母的外部参照，并暴露本系统与上传者的较大选择差异。最终牌组能产生可描述的共现簇，但目前不足以作为强制构筑方向：到第三幕子样本的主模型六组两两比较全部无法分辨；k=3/4/5、三个初始化合计 57 对比较也全含零。

全体牌组中存在 25 局零胜的小簇，标签集中在 `SPOILS_MAP` 等 ID；它可能反映死亡时点/未成型牌组，不能命名成“必败流派”。报告不把拿取率、拿后胜率或共现 lift 转换为牌值、协同收益或最优构筑。

## 从数据产生的构筑簇

仅 v0.111，最终牌组二元 TF-IDF + 球面 k-means。固定随机半数玩家发现、另一半玩家评估；不使用胜负生成特征或质心。预设主模型 k=4/seed=24，另保留 k=3/5 和 seed=240/2400 的敏感性结果。标签按组内卡 ID 的相对 lift 自动产生，编号不代表预设“毒/刀/弃牌”等流派，也不跨模型对齐。

全体训练 922 局、评估 817 局；到第三幕范围训练 519 局、评估 354 局（来自全体同一玩家划分）。每组的分母如下：

| --- | --- | --- | --- |
| all / 0 | 252 / 69 / 40 | 27.4% [20.4, 40.0]% | RICOCHET, REFLEX, TACTICIAN, DAGGER_THROW |
| all / 1 | 284 / 64 / 35 | 22.5% [15.2, 30.5]% | INFINITE_BLADES, PHANTOM_BLADES, KNIFE_TRAP, DAGGER_SPRAY |
| all / 2 | 25 / 0 / 15 | 0.0% [0.0, 0.0]% | SPOILS_MAP, FLICK_FLACK, STRIKE_SILENT, NEUTRALIZE |
| all / 3 | 256 / 67 / 39 | 26.2% [19.2, 37.2]% | BUBBLE_BUBBLE, MIRAGE, ACCELERANT, HAZE |
| reached_act3 / 0 | 60 / 36 / 23 | 60.0% [50.0, 70.8]% | ASSASSINATE, DAGGER_SPRAY, BLADE_OF_INK, PRECISE_CUT |

| reached_act3 / 3 | 144 / 86 / 33 | 59.7% [49.2, 69.9]% | PANACHE, UP_MY_SLEEVE, KNIFE_TRAP, TRACKING |

零胜 c2 的玩家 bootstrap 区间退化为 [0,0]，不能解释成真实胜率严格为零；其独立二项 Wilson 上界为 13.3%，也仍未解决玩家聚类与存活偏差。全体主模型其余三组两两差别均无法分辨；与 c2 的差异受边界正态近似及死亡时点影响。

到第三幕主模型最大的点差为 c0−c2：+8.7 pp，同时 95% 区间 [-9.9, 27.3] pp。所有 57 对第三幕敏感性比较均含零，不意味着流派等效，而是现有样本/分组不足以分辨。每个模型内用玩家簇标准误 + Bonferroni 同时区间；跨 18 个模型无统一校正，区间条件于已训练质心，未包括重新训练的不确定性。

即使第三幕范围仍使用最终牌组，带有未来取牌与结局信息；要证明早期“往哪个方向走”有效，需要固定早期里程碑的牌组状态、足量后续结局和前瞻验证。这份数据当前只能作为候选构筑关联与提问线索。

## 与本系统历史大脑拿牌对照

自身日志按固定字节前缀冻结（见 `own_manifest`），取已结束 Silent A10 的 368 局，成功 Codex `reward/card`、每局/幕/层首个成功选择。358 局贡献 4,728 个奖励点，其中跳过 670；排除 101 次重复/重访和 218 条非 Codex 或失败记录。缺少历史 `accepted` 字段时要求有合法答案且无 error/problems；这不是完整纯 Codex 对局筛选，也不是最新策略的单独测量。日志解析排除为 `{"brain.jsonl": {"invalid_json": 2}, "runs.jsonl": {}}`；没有复制原始题面或局标识。

## 建议交付去向
