主分析单位为实际 Boss 战首试：仅 T1、首试、实际选择可绑定、模拟 reference.enemyIds 与实际 encounter 完全一致的 B2 记录。每场只取最早有效决策；同场重复问题、后续回合、SL 重试不得变成独立结局。SL 首试明确 won=1、died/predicted_death=0；没有 SL 时仅用精确匹配的实际首场结局，未知不猜。并列比较只描述实际执行选择，未执行候选的反事实胜负未知。

比较固定 ridge logistic 模型：截距和 logit(模拟校准胜率)，对照再加标准化 S；胜率只为 logit/logloss 截断至 [1e-6,1-1e-6]，不改原输入。训练内标准化，固定 ridge=1（非截距），不搜索参数。按 run 整组留一交叉验证，逐 Boss 与幕报告；不足两个类别的训练折记未知。主分数为每场 Brier、logloss，增量定义为仅胜率损失减去加 S 损失；按 run 成组配对 bootstrap 2000 次，固定 seed=20261016。分层样本不足、区间覆盖零均不能声称已证明增量。
