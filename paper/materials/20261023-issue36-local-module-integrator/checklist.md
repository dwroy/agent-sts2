# 发布组合的本地模块自查

主管本轮要求：发布的脚本引用的本地模块都必须在组合内。作为精确叶清单、知识快照和消费者定向检查之外的准入项，后续组合持续保留。

1. 在实际待发布组合中列出新增/修改入口及其保留调用者；检查 shell 的 source/exec/解释器脚本路径、Python 本地 import/文件加载和其他运行时模块引用，递归核其本地依赖。按组合根目录及真实运行 cwd 解析，不能借主检出或开发树中的文件补齐。
2. 为每条本地依赖记录调用者、位置、目标、组合中的 blob/模式及 SHA。缺文件或缺可解析的传递依赖即停止交付；动态路径须读源逐项解析，静态扫描未识别不算通过。原有可选路径须同时核其存在性门和缺省行为，不能把本次已执行的 seal 当可选。
3. 定向固定夹具须调用组合内真实适配器，外部 Herdr/进程/回收动作才用固定桩。只给适配器造同名 stub 的测试不证明组合依赖完整。继续保留缺模块拒绝及原权限/终态/绑定反例，不执行生产 seal 或关闭 pane。
4. 发布前原 ops 以届时实际 live 重核同一依赖清单与最新知识；发布后读回实际树。旧自然失败不覆盖，不对退出的主管补 seal，下一自然验收保持独立。
