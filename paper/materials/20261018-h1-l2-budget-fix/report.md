## 最小实现

仅生产循环对 Silent 建立 H1 父预算；每次 L2 路由调用在同一时钟上创建独立 90,000 ms 子预算。验证、重问、等待及取消仍受本次路由调用的一个硬截止；到期仍用既有 L1 兜底，不换模型/强度。父预算在子阶段暂停，之后原余量恢复；B3 的原 11 秒计算上限、共同前缀、样本数和 C1/C2 规则未改。

G2、P1/P2 处于 shadow 时、C2 反事实、F48 汇总和构筑观察使用独立子预算；上限仍取进入该阶段时父预算的原剩余额度，没有增加 worker 或改模拟内容。P1/P2 的 on 路径仍计入真实计算。H2 和 Jev shadow 原有的事后顺序和 60/5/1 秒独立额度保持。

日志增加 `shared_actual_ms` 和 `independent_actual_ms`，并逐阶段记录 scope / budget_ms / actual_ms / timed_out / shared_remaining_ms。原 `actual_ms` / `turn_actual_ms` 继续包含所有计算，不能再拿全部耗时与父共享额度单独比较；应核共享耗时及各独立阶段自己的上限。B3_current 计时排除嵌套独立 shadow / L2，避免重复计时；该 stage 的 budget_ms 是进入时父共享余量，真实 B3 自有截止仍由原 diagnostics / runner deadline 表示。
