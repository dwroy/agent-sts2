## Notes and definitions

- Minutes: console process logs (start = file name, local UTC+8) mapped to a run when they start after the previous run's last `finished run` line and at or before this run's last one. active = sum of each process's `elapsed` (restart gaps between processes excluded; a stall inside a process before it died, e.g. VNWR's Jev 520, stays in); wall = first start to last finish. Restarted runs: VNWR16YEJASM (2 processes).
- Rollout-best: rows carrying `rollout_best_chosen`, share true among non-null (null = no rollout best or no parsable pick).
- Code-alone combat share: COMBAT rows excluding `combat/plan-continue` (plan execution); decider == `code`. `code-fallback` rows (Jev failed/timeout) are not counted as code.
- Focus: rows with a `focus` map (V3 target-option change); chosen = Jev's answer key is a focus-tagged plan key (before any HP-guard swap).
- HP guard: COMBAT rows whose rationale contains `HP guard` (Jev-pick replacement and code's own over-bound replacement). Non-combat mentions (event option filtering) are excluded: V2 0, V3 0.
- Potions drunk: rows whose chosen action is `use_potion` (Jev picks, plan steps `POTION:` executed as plan-continue, code's plan-potion). Room: boss = floors 17/33/48; elite = MAP decision on the previous floor chose an `Elite` node; everything else (Monster, Unknown) = hallway. Drinks whose room could not be parsed (counted as hallway): V2 0, V3 0, V3-pre 0.
- Potions held entering a boss: potion slots filled in the fingerprint of the first COMBAT row on floor 17/33/48. Last boss fought = highest such floor reached.
- Random-potion MC: rows whose `potions.random` is non-empty (logged from V3-pre on); picked = Jev's answer is a potion key whose slot holds one of the MC potions. Other potion picks on those rows: V3 0, V3-pre 0.
- DeepSeek tokens: runs.jsonl `ds_tokens_in/out`, `ds_cache_hit` where present (V3); otherwise summed from decision rows' `deepseek` block (V2, V3-pre).
