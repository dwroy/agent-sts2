# #55 策略库情境检索与剧本段落合同

`kb_strategies` 只读当前角色正式的 `strategy-entries.json`，不扫描 scratch、学习报告或候选剧本。Silent 按题型、幕、Boss、HP、牌组张数与明确卡牌名称/ID的已有 trigger 筛选，具体条件多的条目优先，其次可信度、ID。触发条件合取；不把未满足条件的条目当关键词搜索结果。铁甲原工具描述与空库行为保持不变。

输入 `{"query":"*"}` 默认返回前三条；也可按 ID/关键词细查，`limit` 为1–6，`offset` 为0–500。结果含 `total_matches`、`next_offset`、`returned`、`omitted`、`oversized_skipped`。`omitted` 指本页以外的全部匹配条目，包含前页；按 `next_offset` 可遍历同一未变化的发布库。每页含库 SHA；库 SHA 变化时重新查询。来源摘要仅包含本页条目，整页 UTF-8 ≤24,000字节，不截断正文或证据。单条证据超限时整体跳过并计数；不让它堵住后续小条目。分页不表示需要把全库读完。

条目保留 ID、版本、来源、置信度、完整支持/反证及样本口径。外部聚合仍与自有对局分账，不合并重复分母，不提升可信度。没有库、库损坏或不匹配时返回空。

## #54 几何与 #51 发布对接

有显式流派绑定的条目时，消费者才读取 #54 的 `external/sts2fun/builds-v1/archetypes.json`。固定 SHA 为 `6a254692c7c66782a4d698003068bdc653277e6980f116f9683fe86e2ccd1a8c`，模型 SHA 为 `857cc1bfc55906cb69186c439cad36d86f260af340b0d0b24cb5af3284122342`。仅 Silent A10 使用。按该模型的二元 TF-IDF 对当前已持有卡牌 ID 归一化，再算8个中心的余弦相似度；重复副本不增加权重。原始 mod 牌组优先，缺失时读明确的 `facts.deck` 等牌组字段；不读待选牌、不猜中文映射、不使用未来终局或胜负。零重叠、零相似、并列最近、缺失/损坏模型均不返回绑定段落；普通策略仍可用。

`trigger` 新增可选的严格字段：

```json
"archetype": {
  "model_sha256": "857cc1bfc55906cb69186c439cad36d86f260af340b0d0b24cb5af3284122342",
  "version": "v0.111",
  "clusters": [0]
}
```

上例仅展示字段形状，不赋予簇0任何流派名称或游戏结论。模型、参考版本、最近簇均须相符，此外照常满足题型/幕/Boss/牌组等条件。结果附模型来源/SHA、参考样本873、当前相似度、第二名差值、重叠词数及原统计限制。最近几何只用于查阅相关文字，不能证明流派成型、优劣、最佳转向或安全HP；低差值与早期模糊性须由读者结合限制判断，不由开发者创造游戏阈值。

#51 的正式发布者可把经学习者确认的剧本相关段落分别存为合法 StrategyEntry：段落各有稳定 ID，正文仍≤1200 UTF-8字节，按题型/幕/Boss与显式模型绑定筛选，证据及未知项完整保留。可在既有可选元数据里附剧本父 ID/段落名，但不以元数据替代 evidence。新增段落不代表新增独立学习成果。现有无绑定策略不受影响；原 inline 消费者没有当前几何时不会注入绑定段落。

毒008的 `silent-external-poison-build-playbook-c1` 是待发布的 knowledge 候选，含现 schema 无法完整表达的前缀条件、缺新三输入中的自有完整局，**本改动不转换、不复制、不发布该候选**。正式段落必须由学习/发布 owner 依据实际证据确认适用条件与样本，不把候选的终局簇标签直接当当前触发事实。后续 #54 模型升级须显式更新校验和与绑定，旧簇号不跨模型套用。

## 题面与读回

非零匹配时题面仅追加一句“本题有 N 条相关策略/剧本可查。”，N是当前全部匹配条目数，不是返回数、剧本父数或已查询命中数；不注入正文、ID或强制查询顺序。rk/经验原通道和 Jev 出牌逻辑不变。

router 原 `query_audit.strategies.hit_ids` 只计实际成功返回条目，不计提示、候选或报错。`agent/tools/brain-agent-report.ts` 新增 `strategy_runs`：每局去重条目数/ID、逐题ID、查询题数，以及策略工具执行耗时和整题时延的中位数/P95，二者分开。命令沿用 `npx tsx tools/brain-agent-report.ts <brain.jsonl> [run-id ...]`。上线后由原集成/ops链冻结自然局窗口读回；固定测试和源码交付不代替正式剧本发布、自然采用或耗时收益验收。
