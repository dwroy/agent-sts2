# V5 构筑模块

Roy 于 2026-10-13 授权：补齐构筑模板与伤害/回合接口，从历史供给机会模拟成型路径，先记录预测校准，再用于真实选择。同日随后明确取消 V5 的 30 张牌上限：运行闸和构筑预测均不设固定张数预算，拿/跳/删由大脑结合核心兑现、稀释、伤害/回合及存活权衡；其他角色默认关闭构筑模块。学习者提供角色知识，构筑模块负责计算，大脑保留最终选择权，原 ops 管理运行与阶段验收。原 V4 30 张实验及其测试作为历史保留。

## 数据与边界

`knowledge/characters/<角色>/construction-templates.json` 保存学习者模板：AND 条件组、组内 OR 替代件、数量、不同牌名要求、升级条件、遗物及证据 SHA。首批四套模板机械转换自原全历史学习者 `match()` 和 construction-templates 报告，仅标 candidate；升级需求接口可表达，未从旧报告推出新升级规则。组件共现不代表合法启动、循环闭合或稳定胜率。模板不规定目标张数。

`construction-opportunities.json` 由 `knowledge/builders/build-construction-opportunities.py` 从本角色已结束对局的 Codex accepted 选牌题面构建。保留未选择的牌、完整选项组和价格，来源带原日志偏移/长度/SHA。商店只计首次可读完整库存；奖励按同局/幕/层/整组选项去重。日志中的未见选项、未访路线、特殊奖励和金币增长不补造。每局原知识刷新链更新，写临时文件后原子替换。不同角色不混用。

消费者根据实际角色/进阶/幕、未来节点楼层附近 ±4 的历史机会抽样；同局及当前时刻之后的数据排除。这个窗口和补组件策略是计算条件，尚未证明为最优策略或真实游戏掉率。来源偏差、跨房相关性、有限历史样本与蒙特卡洛误差分列；输出有效机会数、独立局数和最小分层池，不能拿重复抽样数当独立历史局数。

## 计算

`agent/src/construction/planner.ts` 对每个选项、每套核心使用相同场景身份。未来每步只揭示本步选项，不让策略读取后续场景。默认补组件策略只比较签名缺口，显式计价格/名额；可注入基于已揭示状态的策略。`applyBuildActions` 逐步验金币和牌数，不借未来删除/收入来执行当前购买。

输出三个不同目标：

- `conditionalSignature`：假定能经过指定机会、未知事件不改变牌组、按已声明补组件策略选择的组件签名概率。
- `signature`：保留未知机会的缺失分母及最坏/最好界，未知不填失败或零收益。
- `aliveAndFunctional`、`terminalWin`：只有逐步战斗与核心资格证据完整才计算；过本幕 boss 不等于整局通关。

`combat.ts` 复用 `fightSample`，传递剩余 HP、复活资源及已消耗药水身份。调用方负责提供有证据的本步遭遇和牌组，未知返回 null。核心可运转资格由原学习者的验证器提供，不从持牌签名倒推。当前在线首版尚未具备完整未来遭遇/金币/遗物联合模型，因此在线后两项保持 unknown，不能用独立概率相乘补齐。

真实消费者 `withConstruction` 在原 hand loop 的大脑调用前运行，覆盖奖励、商店、移除/升级选择、休息、事件和路线题；已明确的奖励、购买、移除、升级和休息可投影，未知事件/变换/未支持的复合资源变化显式置空。每项投影沿当前路线推算，未比较其他路线时不能声称路线最优。当前商店条目逐项比较；整份购买计划的合法性仍由原多步购物闸逐步检查。

原 boss 模拟的精简题面现在保留总伤害、实际模拟回合、首轮/后续伤害、逐轮伤害曲线及完整战斗逐场 DPR 分布。准备轮和终止轮均计入，胜/死分列，截断/超时另列。逐轮曲线的分母只含模拟到该轮的样本；不拿成功启动后的窗口代替全战 DPR。

## 阶段与记录

`CONSTRUCTION_MODE=shadow` 是首发默认值。构筑预测记在原 `decisions.jsonl` 的 `boss_sim.construction`，不向大脑发送概率表，避免未经验证的数字先改变采样政策。无需新模型、守护进程或研究会话。原 agent tab 显示模块状态和耗时；只记录汇总和证据版本，不保存海量逐场景副本。

`advisory` 将比较表实际加入题面，大脑可在原 `run_plan.construction` 保留 `primary/alternatives/checkpoint/reason/pivot_if`，存入原计划日志并回到下次题面。未知核心 ID 不入库，其他角色不解析。每次新题面重算预测；转向由 Codex 在同一计划中解释，代码不按候选概率自动抢答。

`off` 关闭构筑模块。run-config 登记架构、模式和政策，单次预测记录资料 SHA 和运行阶段。完整源码/知识/配置及实际大脑回答继续走原记录链。

## 验收与后续原任务

固定测试覆盖联合路径死亡、资源顺序、升级/重复/替代件、整组选项、当前局/未来数据隔离、截断与未知、真实模拟器复用、题面 shadow/advisory 和其他角色等价。原签名转换另核与原学习者函数等价。

`eval/construction.py` 对逐项绑定角色/局/决策/核心/指标/截止阶段/模型/政策/SL 的预测与真实结果计算 Brier、偏差和分桶校准；去重，剔除缺证、变线、变政策和未完成窗口。输入实际证据由原日志/学习者提供，工具不从历史最终牌组倒造前瞻预测。机会重放、集齐、可运转和通关分别评价。固定回放不替代自然采用/效果。

原 `roy-20261011-silent-core-cycle-quantitative-learning` 及 `roy-20261012-concrete-core-decklists` 的核心资格、P1/P2、模拟校准与自然效果仍沿同 owner/thread 完成；没有新增同题全历史研究。在线完整成型/通关率、其他路线联合模拟及自然校准未完成时保持公开缺口。不得因 V5 框架发布就关闭这些父要求。

从 shadow 晋级 advisory 由原 ops 根据实际校准回执登记配置分界，不能把测试通过当晋级证据。阶段二自然数据尚未产生时不自动晋级。回退首先设 `CONSTRUCTION_MODE=off`，下一局读取；如需撤回源码则 revert 对应行为发布提交并登记新编号，不改旧日志，不重启当前局。
