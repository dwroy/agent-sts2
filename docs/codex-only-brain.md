# Codex 大脑等待与战绩口径

Roy 2026-10-07 09:00 授权的独立架构功能；没有新增游戏知识。全局引擎政策适用于所有角色，铁甲的策略、求解器和知识数据保持原样。

生产入口 `createRouter` 强制 Codex，忽略历史引擎选择和回退配置。路线、选牌、事件、商店、休息、整局计划及既有战斗计划经过相同路由。Jev 战斗执行、代码推演和安全执行闸继续按既有职责工作；闸拒绝脑答案不能选择另一个选项。

可恢复的额度、登录、预检、限流、服务故障和超时会暂停原题。退避为 5、15、30、60、120、300 秒，此后最多 300 秒一次；每段睡眠不超过一秒，等待没有耗尽后代答的出口。连续两次超时保留既有十分钟休息，每次探测/睡眠有上限。预检与使用额度保护必须重新通过，才重新询问原输入/题号。空答案、验证失败和合并题遗漏的路线/整局计划重新由 Codex 回答。程序错误保留原因并停止该决策，不循环吞掉。

暂停后每 15 秒写 `logs/brain-wait.json` 和 `brain-wait.jsonl` 心跳；记录 pid、run_id、question_id、decision_type、原因、时间、重试次数、暂停时长和原预算。`ops/inbox-dev.md` 每次暂停/恢复/取消/程序故障各一条，重试及心跳不重复通知。普通额度恢复全自动，继续同一题/同一局；等待中没有游戏动作。暂停时长（包括失败的请求）从原 max-minutes 与 combat grace 中扣除，正常思考、成功调用及其他原预算照常计时；总墙钟时间另保留。显式 Codex 调用数上限不会自行重置，耗尽后等待或由运维在保留原局的情况下调整后重启。

SIGINT/SIGTERM 和 `ops/STOP` 可取消等待；留下原决策、存档和日志。CLI 退出 75（取消）或 78（程序错误），autoplay 停在原局，避免自动重启风暴。修复后清除终止的 `brain-wait.json` 标记可恢复同一存档；进程内额度/登录恢复不需要清除文件。不能用清标记绕过登录、隔离或额度自检。心跳超过 45 秒或进程身份不符时仍报警；终止标记不冒充活跃心跳。运维脚本来自主检出，合入 live 后需由运维核实主检出同步和运行脚本版本。

战绩政策 `codex-successful-brain-v1`：只根据 brain.jsonl 实际成功回答。新日志显式 `accepted=true`；旧日志需要 answer 非 null、无 error、无 problems。每个 `(question_id, engine)` 成功只计一次；历史无题号逐行计。主标签按题型计成功数量，附带路线/整局计划数量另外列出，不重复加入主题总数。失败调用、兼容 deepseek_calls/ds_*、启动配置和 fell_back_from 都不能当作成功引擎。

成功引擎只有 Codex 且所有已记脑题都有成功答案才默认纳入。只有 DeepSeek 为 deepseek；两种以上成功引擎为 mixed；缺成功回答/引擎、缺脑日志或未解决的脑题为 unknown；其他单一引擎为 other。归类保留成功数、题型、时间范围、覆盖声明和排除原因。旧日志无题号的失败不能证明后来成功的是同题，保守列为未知。已有日志之外的遗漏题无法复原；“完整”仅指可核验的已记脑题，不能假称完整历史。

metrics、学习曲线、论文和自动 climb 采用相同默认口径；混合及未知不会升阶。`--include-non-codex` 显式显示全部原始战绩（不改变自动升阶）。首次尝试与 SL、角色隔离继续保持；复盘、学习证据、成功/失败请求及成本始终保留。成本曲线的原始局数/token/费用覆盖所有引擎，胜数用 Codex 口径，原始胜数及来源分组另外显示。每 Codex 胜费用包括整个实验已知费用，不能解释为该局的边际费用。

论文输出在重建前归档旧快照；旧报告不回改。来源未知的历史可用显式全引擎口径重现原成绩，不能补造引擎。固定夹具测试不调用真实模型、网络或 play；旧引擎适配测试通过测试专用历史适配器保留。
