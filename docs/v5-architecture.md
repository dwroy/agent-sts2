# V5 架构与发布边界

核对日期：2026-10-14。当前正式行为版本为 **V5-R341**；实际运行以 `eval/versions.json`、live 提交、`logs/run-config.jsonl` 和请求/动作原件为准。Jev 新请求替换已批准，仍在实现；本页不把设计、测试或排队当成上线。

V5 复用 [V4 基础模块](v4-architecture.md)，增加独立构筑预测、同题完整战斗评估及 Boss 相对效率指标。游戏知识继续只由学习者从本角色对局产生；代码和模型不得补造未观察机制。

## 职责与数据流

| 部分 | 职责 |
|---|---|
| 代码与模拟器 | 生成合法候选，完成已支持候选的目标样本，计算数值与误差；保留样本身份、未知和模型限制，执行合法性及原存活/资源保护。 |
| Jev | 在既有战斗候选集合中选择，读取结果、代价、风险、必要条件与经验；算术和完整模拟由代码完成。新的请求投影应替换旧冗余明细。 |
| Codex 大脑 | 路线、构筑、事件、休息和整局方向等高层决策；本次 Jev 请求优化不迁移这些路由。 |
| 学习者与 ops | 学习者提供机制、经验及校准证据；ops 核实际发布和消费者读回、管理原对局与回收。角色数据隔离，已发布公共经验按共享规则使用。 |

完整计算 → 审计记录及候选事实 → 针对消费者的请求投影 → 模型选择 → 执行闸 → 实际动作。审计数据的完整性不要求把全部中间数据发送给模型。

## 已发布的 V5 能力

- **构筑预测**：从本角色历史供给抽样，区分组件签名、合法运转和最终通关。未来概率默认 shadow；advisory 仍需对应条件的真实前瞻校准，未验证项保持 unknown。
- **同题构筑评估**：拿/跳/买/删/升级等候选复用当前 B3 结果，提供战斗兑现与配对差，并将构筑方向写入既有结构化计划。未来概率未晋级不阻止当前候选评估。
- **必需完整计算**：Silent 已支持的候选完成目标配对样本后才决策，B3 默认1000、B2默认600。旧11秒预算只作延迟目标，失败/不完整保持等待；计算结束重读局面。相同输入与等价候选可复用结果，不削减候选或样本。
- **核心公式**：`S = my_dpr / boss_hp - enemy_dpr / my_hp`。双方 HP 固定为模拟入口参考量，DPR 使用同一窗口并含准备轮；战中题只覆盖剩余战斗。原存活、资源、模型可信度与未知归属约束保持，S 不是胜率。
- **无固定牌数上限**：V5 Silent 已取消原30张上限；构筑取舍由实际证据和模型决策处理，不在文档中新增游戏策略。

完整算法、开关与未覆盖情况见 [构筑模块](v5-construction.md) 和 [量化接口](quantitative-play.md)。关闭构筑预测不能绕过 Silent 的必需 Boss 计算；撤回已发布行为须由 ops 精确回退并登记新号。
